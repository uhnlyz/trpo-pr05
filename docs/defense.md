# Подготовка к защите — практическая работа № 5

## Что показать
1. Запустить сервер: `php -S localhost:8000 -t public`.
2. Показать 12 товаров, три категории, среднюю цену и количество активных товаров.
3. Открыть три файла из `dataset`.
4. Показать GET-фильтр по категории.
5. Открыть `src/Model/Product.php` и объяснить свойства, конструктор и методы.
6. Открыть `src/Service/CatalogService.php` и показать, где JSON превращается в объекты.
7. Показать проверку некорректного конструктора.

## Понятия простыми словами
- **Класс** — описание данных и действий объекта.
- **Объект** — конкретный экземпляр класса, например один товар.
- **Свойство** — данные объекта: id, название, цена, категория.
- **Метод** — действие или вычисление, связанное с объектом.
- **Конструктор `__construct()`** — вызывается при создании объекта и задаёт начальное состояние.
- **`$this`** — ссылка на текущий объект.
- **`private`** — свойство доступно только внутри класса.
- **`InvalidArgumentException`** — исключение для некорректного аргумента.
- **Сервис** — отдельный класс, который выполняет операции над группой объектов.

## Контрольные вопросы
**1. Какие входные данные получает приложение и где они находятся?**  
`products.json` содержит товары, `categories.json` — категории, `class_requirements.csv` задаёт свойства и типы для классов.

**2. Какой участок кода отвечает за преобразование данных в интерфейс?**  
`CatalogService` читает JSON и создаёт объекты `Product`. `public/index.php` получает объекты и выводит их свойства и результаты методов.

**3. Какое ошибочное состояние проверялось?**  
Создание товара с нулевым идентификатором, пустым названием и отрицательной ценой. Конструктор выбрасывает `InvalidArgumentException`.

**4. Что можно изменить при увеличении проекта?**  
Добавить репозиторий, отдельные шаблоны, контроллер и автозагрузку классов через Composer. Сейчас используется простой `require_once`.

**5. Как проверить работу после клонирования?**  
Установить PHP 8.0+, выполнить команду запуска из README и открыть `http://localhost:8000`.

**6. Чем серверное выполнение PHP отличается от JavaScript в браузере?**  
PHP формирует HTML на сервере. JavaScript в браузере может менять уже загруженную страницу без повторного запроса.

**7. Когда полезен конструктор класса?**  
Когда объект должен сразу получить обязательные значения и пройти проверку начального состояния. Так нельзя создать товар без названия или с отрицательной ценой.
